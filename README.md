# O que é JavaScript? JavaScript é uma linguagem de programação usada para adicionar interatividade às páginas web. Enquanto o HTML define a estrutura da página e o CSS define o visual, o JavaScript permite que a página responda às ações do usuário.

# Como o JavaScript se relaciona com o HTML e CSS - HTML - Estrutura (texto), CSS - Estilo (Cores Animações), JavaScript - Comportamento (Interações)

# Onde JavaScript pode ser usado no HTML - Pode ser inserido usando o <script> e </script> dentro do HTML. Ou, em um arquivo dentro da pasta deve ser criado com o nome: (script.js)

# Declaração de Variáveis - Elas armazenam valores como: let nome = "João"; ou const idade = 20;

# - Diferença entre Var, Let e Const - Var = Antigo, Evita-se usar. Let = Valor pode mudar. Const = Valor fixo (Não pode mudar)
